# WordPress-style content design

KOVCHEG Blog 3.6.0 uses three primary content concepts:

- **Post / Запись** — chronological blog content shown in the feed and assigned to categories.
- **Category / Рубрика** — taxonomy for Posts only.
- **Page / Страница** — permanent standalone content that may be linked from navigation menus.

Supporting sections such as Media, Comments, Menus, Appearance, Users and Settings remain available, but they are not content types.

Portfolio, tags, presets, demo content and section builders are not part of the normal content workflow. Existing portfolio rows are migrated to Pages so user data is preserved.
