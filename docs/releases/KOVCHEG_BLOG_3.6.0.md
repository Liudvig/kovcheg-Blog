## Новая основная логика

KOVCHEG Blog переведён на понятную модель обычного блогового движка:

- **Записи** — новости и статьи;
- **Рубрики** — тематическая группировка записей;
- **Страницы** — постоянные разделы сайта.

Рубрики относятся только к записям. Страницы публикуются отдельно и могут добавляться в меню. Меню принимает страницы, рубрики и произвольные ссылки.

## Что убрано из обычной работы

- отдельный тип «Портфолио»;
- теги;
- конструктор секций в редакторе;
- пресеты и демонстрационный сайт;
- Widget Studio и сложные служебные разделы из основного меню;
- выбор типа материала внутри редактора;
- портфолио-поля, ручной порядок и другие редкие поля.

Существующие работы портфолио не удаляются: миграция переводит их в обычные страницы. Старые адреса портфолио перенаправляются в блог или на соответствующую страницу.

## Studio

В KOVCHEG Studio появились отдельные разделы:

- Записи;
- Рубрики;
- Страницы.

Редактор стал компактным и использует один классический документ. Тип записи фиксирован выбранным разделом. Для записи доступны рубрики и краткое описание; для страницы — постоянный URL и добавление в меню.

## Производительность

- Builder больше не загружается в bootstrap каждого запроса;
- Studio не подключает стили и JavaScript конструкторов и Widget Engine;
- главная страница больше не запрашивает и не выводит портфолио;
- preview и публичный рендер не выполняют запросы тегов и portfolio metadata;
- сохранение использует только Classic Editor.

## Миграция

`migrations/20260806_wordpress_content_model.sql`

- переводит `portfolio` в `page`;
- удаляет связи рубрик со страницами;
- не удаляет тексты, изображения, страницы или записи.
