## Главная логика

В системе осталась одна сущность содержимого — **Страница**.

Рубрика является необязательным разделом для группы страниц. Её можно назвать:

- Новости;
- Блог;
- Документы;
- Проекты;
- Отчёты;
- любым другим названием.

Отдельных сущностей «Блог», «Запись» и «Портфолио» больше нет.

## KOVCHEG Studio

- из меню удалён раздел «Записи»;
- основными разделами стали «Страницы» и «Рубрики»;
- верхняя кнопка создаёт страницу;
- список страниц заменён компактными карточками;
- редактор всегда сохраняет страницу;
- к любой странице можно прикрепить одну или несколько рубрик;
- краткое описание доступно для каждой страницы;
- старые адреса Studio переводятся в новый раздел страниц.

## Публичный сайт

- главная показывает рубрики и последние страницы;
- рубрика открывается как самостоятельный раздел сайта;
- страница получила новый чистый шаблон документа;
- добавлены хлебные крошки, рубрики, крупный заголовок, аккуратная обложка и нормальная типографика;
- авторская и блоговая служебная информация убрана из обычной страницы;
- связанные страницы подбираются по общим рубрикам;
- комментарии показываются только когда включены;
- старые URL `/blog/{slug}` и `/portfolio/{slug}` переводятся на `/page/{slug}`;
- верхние `/blog` и `/portfolio` остаются только техническими алиасами той же главной страницы и не образуют отдельных разделов.

## Portal Matrix

Восстановлен рабочий метод ремонта матрицы Portal:

- создаются только отсутствующие системные виджеты;
- пользовательские виджеты и их настройки не удаляются;
- восстанавливаются логотип, главное меню и профиль в шапке;
- в левой колонке появляется вертикальное меню разделов;
- в правой колонке восстанавливается поиск;
- в подвале восстанавливаются подписка и служебный блок;
- ремонт повторяемый и безопасен при повторном запуске.

## Сохранность данных

Миграция `migrations/20260806_z_page_category_core.sql` переводит существующие записи и работы портфолио в страницы.

- тексты не удаляются;
- изображения не удаляются;
- ярлыки URL сохраняются;
- история изменений сохраняется;
- рубрики старых записей сохраняются.

Миграция специально выполняется после миграции 3.6.0, чтобы не потерять связи рубрик.

## Проверка

Проверяются:

- PHP и JavaScript syntax;
- модель «Страницы и рубрики»;
- классический редактор;
- маршруты страниц и старые совместимые URL;
- миграции на MariaDB и MySQL;
- повторный запуск migration runner;
- восстановление и рендер Portal Matrix;
- главная, `/blog`, `/portfolio`, XML, RSS, robots и Studio;
- отсутствие сохранённых секретов и runtime-файлов.
