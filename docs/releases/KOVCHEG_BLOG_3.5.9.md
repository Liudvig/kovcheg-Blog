## Что исправлено

- предварительный просмотр материала теперь прокручивается как обычная страница;
- встроенный предпросмотр классического редактора получил собственную вертикальную прокрутку;
- опубликованный материал больше не остаётся на адресе Studio Preview;
- старые ссылки вида `/studio/content/{id}/preview` для опубликованных материалов переводят на итоговый адрес;
- сохранённый черновик можно открыть редактору прямо по будущему каноническому адресу без публикации для посетителей;
- статус «Опубликовано» означает публикацию сразу, даже если в поле даты случайно осталась будущая дата;
- будущая дата применяется только со статусом «Запланировано».

## Постоянная ссылка

В редактор добавлен отдельный блок «Адрес страницы»:

- виден полный итоговый URL;
- отдельно редактируется slug;
- URL автоматически меняется при выборе типа «Публикация», «Страница» или «Портфолио»;
- ссылку можно скопировать;
- итоговую страницу можно открыть в новой вкладке;
- опубликованный публичный материал можно сразу передать в редактор меню.

## Меню

При переходе из материала в раздел меню:

- нужная опубликованная страница выбирается автоматически;
- её заголовок подставляется в название пункта;
- остаётся выбрать меню и нажать «Добавить».

## Безопасность

- черновики и будущие публикации по каноническому адресу видны только пользователям с правом редактирования материалов;
- для таких просмотров отправляется `X-Robots-Tag: noindex, nofollow, noarchive`;
- посетители не получают доступ к неопубликованному содержимому;
- схема базы данных не меняется, миграции не требуются.
