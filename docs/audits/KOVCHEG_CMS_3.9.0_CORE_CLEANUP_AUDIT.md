# KOVCHEG CMS 3.9.0 — Core Cleanup Audit

Дата: 2026-08-09

Автор и правообладатель: Ланцет Семён Борисович

Лицензия: proprietary / all rights reserved

## Цель

Очистка KOVCHEG Blog / KOVCHEG CMS от исторических слоёв, которые больше не относятся к текущему блоговому движку.

## Текущая модель

KOVCHEG Blog — самостоятельная CMS:

- Записи;
- Рубрики;
- Страницы;
- Медиафайлы;
- Меню;
- Виджеты и зоны;
- Пользователи;
- Брендинг;
- Темы;
- Настройки.

## Найденные кандидаты на очистку

### Старые CMS-названия

Проверить и заменить активные упоминания исторических движков и режимов.

### Социальный слой

Проверить отключение неиспользуемых:

- feed;
- стены пользователей;
- VK/X шаблоны;
- чаты;
- друзья/подписки.

### Старые конструкторы

Проверить удаление из активного runtime:

- demo;
- presets;
- старые builder routes;
- старые редакторы.

### Дубли

Объединить:

- маршруты;
- CSS загрузки;
- Studio assets;
- документацию.

## Правила

Не удалять данные пользователей и публикаций без отдельной миграции.

Не менять историю Git force-push.

Каждый удаляемый компонент сначала проверяется на использование.

## Этапы

1. Runtime cleanup.
2. Studio cleanup.
3. Documentation cleanup.
4. Security review.
5. CI validation.
6. Production deploy.
